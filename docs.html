命令行用法

基本语法

python3 book_to_podcast.py --book PATH [options]

选项说明

Options: --book PATH Book file (PDF/EPUB/TXT/DOCX/HTML) --output DIR Output directory --episodes N Max episodes (0=all) --engine NAME TTS engine preference --format wav|mp3 Output format --script-only Only generate script HTML --no-eq Disable voice EQ --no-noise-reduction Disable AI noise reduction --no-pedalboard Disable pedalboard studio effects --no-rss Skip RSS feed generation --no-id3 Skip ID3 tag embedding --list-engines List available TTS engines -v, --verbose Debug logging

使用示例

完整流水线（默认全部增强开启）

python3 book_to_podcast.py --book your_book.pdf --engine xtts-v2 --format mp3

仅生成剧本（不做 TTS）

python3 book_to_podcast.py --book your_book.epub --script-only

限制集数 + MP3 + 关闭降噪

python3 book_to_podcast.py --book your_book.txt --episodes 5 --format mp3 --no-noise-reduction

列出所有可用 TTS 引擎

python3 book_to_podcast.py --list-engines

TTS 引擎对比

流水线集成 7 种 TTS 后端，按质量分（1-10）自动择优选用。质量分越高代表语音自然度越佳。

引擎质量在线/离线中文支持说明
XTTS-v210在线极佳（声纹克隆）支持零样本语音克隆，可自定义任意音色
edge-tts9在线极佳（自然语音）Microsoft 神经网络语音，4 种中文声线，免费免密钥
MeloTTS8离线优（MIT 神经网络）MIT 协议开源神经 TTS，多语言高质量本地推理
Piper7离线良Rhasspy 项目高性能嵌入式 TTS，低资源设备友好
pyttsx35离线依赖系统语音调用系统原生 TTS 引擎，跨平台兼容
espeak3离线可用（机械音）音素合成器，速度极快但音质机械
ffmpeg-tts2离线差（纯音调）FFmpeg 内置 tone 生成，仅作保底后备方案

REST API 文档

所有 API 响应统一使用 { "success": bool, ... } 格式。成功时业务数据平铺在顶层，失败时包含 "error" 字段。

GET /api/engines

列出所有 TTS 引擎及其当前可用性。

响应示例:

{ "success": true, "active_engine": "edge-tts", "engines": [ { "name": "edge-tts", "available": true, "quality_score": 9, "is_offline": false, "supports_chinese": true, "voice_count": 4, "description": "Microsoft Edge Neural TTS" } ] }

GET /api/health

系统健康检查（30 秒缓存）。验证关键依赖是否就绪。

检查项:

edge_tts · ffmpeg · noisereduce · pedalboard · feedgen · mutagen · langdetect · markdown

响应示例:

{ "success": true, "status": "healthy", "checks": { "edge_tts": true, "ffmpeg": true, "noisereduce": true, "pedalboard": true, "feedgen": true, "mutagen": true, "langdetect": true, "markdown": true }, "output_dir": "/workspace/podcast-output", "upload_dir": "/workspace/.uploads", "timestamp": "2026-07-04T12:00:00", "cached": true }

注："cached": true 仅在返回缓存结果时出现。

POST /api/generate

启动异步播客生成任务。上传书籍文件并触发完整流水线。

请求体: multipart/form-data

字段类型说明
fileFile书籍文件（必填，PDF/EPUB/TXT/DOCX/HTML）
engineStringTTS 引擎偏好
maxEpisodesInt最大生成集数（0=全部）
formatString音频格式: wav 或 mp3
enableEqBool启用语音均衡器
scriptOnlyBool仅生成剧本 HTML
enableNoiseReductionBool启用 noisereduce AI 降噪
enablePedalboardBool启用 pedalboard 录音棚效果
generateRssBool生成 RSS 2.0 feed
embedId3Bool嵌入 ID3 元数据标签

响应示例:

{ "success": true, "job_id": "a1b2c3d4e5f6", "session_id": "a1b2c3d4e5f6", "status": "pending", "message": "Generation started for book.pdf" }

注：job_id 和 session_id 均为 12 位十六进制字符串。

GET /api/jobs

列出所有生成任务，按创建时间倒序排列，支持分页。

查询参数: page（页码，默认 1）、limit（每页数量，默认 50，最大 200）

注：列表视图会自动脱敏 book_path 和 session_output 等敏感参数，完整参数仅在单任务详情接口返回。

{ "success": true, "jobs": [ { "id": "a1b2c3d4e5f6", "type": "generate", "status": "completed", "progress": 100, "created_at": 1783140000.0, "started_at": 1783140001.0, "completed_at": 1783140600.0 } ], "count": 1, "total": 1, "page": 1, "limit": 50 }

GET /api/jobs/<job_id>

查询单个任务的状态与结果。job_id 为 12 位十六进制。

{ "success": true, "job": { "id": "a1b2c3d4e5f6", "type": "generate", "status": "completed", "progress": 100, "result": { "success": true, "total_time_sec": 120 }, "params": { "session_id": "a1b2c3d4e5f6", "engine": "auto" }, "logs": [ { "time": "12:00:01", "level": "info", "message": "Pipeline started" } ] } }

GET /api/sessions

列出所有播客会话，支持分页。

查询参数: page（页码，默认 1）、limit（每页数量，默认 50，最大 200）

{ "success": true, "sessions": [ { "session_id": "a1b2c3d4e5f6", "dir_name": "session_a1b2c3d4e5f6", "title": "用模型思考世界 — 双人辩论播客", "episodes": 3, "duration_min": 4.3, "file_size_mb": 12.5, "has_rss": true, "has_script": true, "created_at": "2026-07-04T12:00:00" } ], "count": 1, "total": 1, "page": 1, "limit": 50 }

GET /api/session/<session_id>

获取单个会话详情，含所有集次信息。session_id 为 12 位十六进制。

{ "success": true, "session_id": "a1b2c3d4e5f6", "title": "用模型思考世界 — 双人辩论播客", "manifest": { "total_episodes": 3, "total_duration_ms": 258000 }, "episodes": [ { "name": "episode_01.wav", "url": "/api/download/a1b2c3d4e5f6/episode_01.wav", "size_mb": 4.2 } ], "rss_url": "/api/rss/a1b2c3d4e5f6", "script_url": "/podcast-output/session_a1b2c3d4e5f6/podcast_script.html" }

GET /api/rss/<session_id>

下载指定会话的 RSS 2.0 feed（XML）。

响应类型: application/rss+xml; charset=utf-8

GET /api/download/<session_id>/<filename>

下载指定会话下的音频文件。

响应类型: audio/wav 或 audio/mpeg（依文件扩展名）

安全特性

特性说明
文件上传限制最大 100MB（可通过 PODCAST_MAX_UPLOAD_MB 环境变量配置）
Session/Job ID 校验正则 ^[a-f0-9]{12}$ 防止路径遍历与非法 ID 注入
静态文件白名单仅允许 .html/.css/.js/.png/.svg 等扩展名，阻止源码泄露
路径遍历防护/podcast-output/ 路由通过 Path.resolve() + relative_to() 验证路径边界
请求限流每 IP 每分钟 60 次请求（静态资源不计入），超 1000 IP 时自动清理过期记录
安全响应头X-Content-Type-Options、X-Frame-Options、CSP、Referrer-Policy 等
XSS 防护所有前端动态内容经 escapeHtml() 转义
请求日志所有 API 请求记录方法、路径和来源 IP
表单字段限制引擎名 ≤50 字符、文件名 ≤255 字符、集数 0-1000、格式 ≤10 字符

Job TTL 清理完成超过 1 小时的任务自动清理

处理流水线架构

增强版流水线共 7 个阶段（A-G），从书籍读取到 RSS 发布完整覆盖。

Stage A: BookReader — 多格式书籍读取

自动检测文件格式，提取章节结构和文本内容。集成 langdetect 进行语言检测， 支持 chardet 编码识别、pdfplumber 元数据提取、ebooklib EPUB TOC 解析、 python-docx Heading 样式识别与 BeautifulSoup HTML 解析。

Stage B: PodcastWriter — 双人辩论剧本生成

将书籍章节转换为双人辩论格式剧本。每集包含 5 个段落：冷开场 → 深度讨论 → 达成共识 → 行动清单 → 下期预告。 阿哲（理论派）解释概念，老K（怀疑派）质疑挑战，输出结构化 HTML 剧本。

Stage C: TranscriptParser — HTML 结构化解析

将 Stage B 输出的 HTML 剧本解析为结构化对话数据，识别角色标签、段落分段与场景标记， 为后续语音合成提供有序的台词序列。

Stage D: EnhancedTTSManager — 7 引擎语音合成

集成 7 种 TTS 后端（XTTS-v2、edge-tts、MeloTTS、Piper、pyttsx3、espeak、ffmpeg-tts）， 按 质量分（quality score） 自动择优选择，并根据角色分配差异化声线， 逐句合成语音。支持运行时可用性探测与自动回退。

Stage E: ProAudioProcessor — 专业音频后处理

三层音频增强：noisereduce 进行 AI 降噪、pedalboard（Spotify） 应用录音棚级效果（压缩/EQ/混响/响度标准化）、FFmpeg 完成格式转换与最终编码。

Stage F: EpisodeAssembler — 集次拼接

将 Stage D 合成的单句音频与 Stage E 后处理结果按剧本顺序拼接为完整单集音频， 生成片头/片尾过渡，输出最终节目文件。

Stage G: PodcastPackagerPro — 发布打包

生成 RSS 2.0 feed（feedgen）、嵌入 ID3 标签（mutagen） 到每个音频文件，并生成节目说明（show notes），完成播客分发包打包。
